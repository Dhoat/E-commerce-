# 🛒 E-Commerce Platform – Golang (Gin) & React

## 🚀 Overview
This is a **full-stack e-commerce platform** built using **Golang (Gin Framework) for the backend** and **React for the frontend**, with **MySQL as the database**. It includes features like **user authentication, product management, shopping cart, and order processing**.

## 🛠️ Tech Stack
### 🔹 Backend:
- **Golang (Gin Framework)** – Fast and lightweight API framework
- **GORM** – ORM for database operations
- **JWT Authentication** – Secure user authentication
- **MySQL** – Relational database for storing product & user data
- **Docker** – Containerized deployment
- **Redis** – Session & cache management (optional)

### 🔹 Frontend:
- **React.js** – Modern UI framework for the frontend
- **Redux Toolkit** – State management for handling cart & authentication
- **Tailwind CSS** – Styling for responsive design
- **Axios** – API communication

## 📌 Features
✔️ User Authentication (JWT) – Register/Login  
✔️ Product Management – Add, Edit, Delete, List  
✔️ Shopping Cart & Checkout Process  
✔️ Order Management – User & Admin Panel  
✔️ Secure API with **JWT Middleware**  
✔️ Database Integration with **MySQL**  
✔️ Docker Support for Containerized Deployment
